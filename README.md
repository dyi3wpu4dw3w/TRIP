# تأمين الرحلة — TRIP

تطبيق لحجز رحلات الباصات بين مدن السودان، اختيار المقاعد، إصدار رقم حجز، ولوحات تشغيل شركات النقل والإدارة.

## ما هو موجود في المستودع
- واجهة React/Vite عربية RTL.
- صفحات البحث والرحلات والمقاعد وبيانات المسافر والدفع التجريبي والتذكرة والحجوزات والطرود ولوحة إدارة أولية.
- مخطط PostgreSQL لـ Supabase في `supabase/migrations/202611270001_trip_core.sql` يتضمن الملفات الشخصية، شركات النقل، الباصات، الرحلات، الحجوزات، المدفوعات والطرود.
- دالة قاعدة بيانات لحجز المقعد مع قيد فريد لمنع حجز المقعد نفسه مرتين.
- سياسات RLS أساسية.

## التشغيل المحلي
يتطلب Node.js. نفّذ `npm install` ثم `npm run dev`. انسخ `.env.example` إلى `.env.local` وأضف رابط Supabase والمفتاح العام بعد إنشاء مشروع TRIP وربط قاعدة البيانات.

## حدود النسخة
الرحلات الموجودة حالياً في الواجهة بيانات توضيحية. لا يوجد مزود دفع سوداني مربوط، ولا يجوز اعتبار الطلب تذكرة مدفوعة أو مؤكدة. لا تُدخل كلمات مرور المحافظ أو بيانات البطاقات. الدفع الإنتاجي يحتاج عقداً وحساب تاجر وواجهات API رسمية، مع Edge Function للتحقق من إشعارات الدفع وتوقيعها.

## قبل إطلاق الإنتاج
1. تخصيص مشروع Supabase مستقل لـ TRIP وتطبيق الترحيل واختبار RLS.
2. تفعيل OTP للهاتف، وإكمال إدارة الشركات والصلاحيات.
3. نقل الواجهة بالكامل إلى قاعدة البيانات وإزالة الرحلات التجريبية.
4. إضافة Edge Functions للحجز وإشعارات الدفع بعد اختيار مزود رسمي.
5. اختبار حجز متزامن، الإلغاء والاسترداد، الشحن، السجلات والتنبيهات.
6. إعداد تطبيق Android، التوقيع، واختبار الأجهزة والنشر.
